## 变更摘要

- **修复：历史/收藏/电视/电台等页面不支持上一首/下一首**
  - 历史、收藏列表点击条目原本只播单条（队列长度为 1），切歌按钮形同虚设；现在按**当前可见列表**建成
    播放队列（只收与目标项同形态的条目——音频与视频分属不同播放内核），点一条即可连续上下切换。
  - 迷你播放器新增「上一首/上一集」按钮（原先只有下一首），并在无相邻条目时**置灰**（原先点击无反应）。
  - 直播电视台/电台：一个频道一次请求、无法预建队列，改为按「点开频道时所在的频道清单」换台
    （分类网格 → 用该分类全部频道；收藏/历史 → 用该列表内同平台频道），按钮文案对应「上一个/下一个频道」。
  - 视频播放页补回「上一集」按钮（竖屏控制条与横屏均补），三处依赖「上一集索引」的自定义无障碍操作改为
    按真实可用性给出。
  - 列表与网格加「正在播放」标记（历史/收藏行左侧暖橙竖线 + 文案；频道/专辑卡副标题与左上角圆点），
    TalkBack 同步播报「正在播放」。
  - 手动切歌与自动续播分离：单曲循环下**手动**点下一首会真的换歌（原先重放本曲 = 按钮像坏的），
    自动续播仍遵循单曲循环；循环/随机模式下手动切歌在两端回绕，顺序播放在两端置灰。

## 本版追加修复（同一内测版内）

### 分类子集页面（独立窗口）

- 分类下钻改为**独立子集页面**（`Screen.OnlineCategoryPage`）：每深入一层都是一个新窗口，
  窗口标题 = 该层分类名，读屏在窗口切换时播报，不再是「停留在模块名 + 只有加载中」。
- 关键实现：`AnimatedContent` 的 key 并入**分类层级路径**（`pageKeyOf`），
  且窗口标题随层级变（`onlinePagePaneTitle`）——只换 key 不换标题时听感上等于没变。
- 底栏三标签与顶栏搜索在子集页面始终在场；返回逐级上溯，文案区分「返回上一级 / 返回媒体首页」。
- 搜索/榜单子页记住来源，从子集页面进入时返回子集页面。

### 月电台子分类无法加载

- **端点缺失**：`GET /v1/video/subcategories` 从未部署到生产（生产版本没有该路由），
  新客户端点「全球电台」国家时 404。已把该端点移植进生产（网盘影视维持生产既有下钻行为不变）。
- **单页体量过大**：省/州电台按抓取页大小一页全下发，实测美国加利福尼亚 625 台 = 203KB，
  客户端 25s 读超时下偶发超时（「有时能加载、有时失败」）。新增 `CLIENT_PAGE_SIZE=100`，
  625 台分 7 页、每页 ≤35KB，翻页走既有令牌。
- 顺带：分类加载失败补诊断日志（原先静默）、失败后可点「重试」按当前层级重拉、
  已登录请求补读超时重试一次。
