- 在线媒体新增音乐、听书、视频、哔哩哔哩四个一级入口；通用视频按剧集和分集展示，Bilibili 保持独立入口。
- 服务端新增四个苹果 CMS 视频资源站和数据库驱动的动态视频站点目录；视频播放支持预热、HLS 缓存、流内广告过滤及一次自动换源。
- 修复妖狐 m3u8 包装页直链解析、多 worker 动态站点一致性和视频分集 TalkBack 语义冗长问题。
