## 变更摘要

**修复在线音乐站点无法播放（0.6.9 起的回归）**：QQ / 酷我 / 酷狗 / 网易云等音乐站点点开歌曲后一律
提示「暂时无法播放这首歌曲」，服务端 `/v1/resolve` 返回 HTTP 422。

根因：`NativeMusicViewModel.startOtherOnlinePlayback` 与 `preResolveOnlineTracks` 用
「`platform.isAudio` 是否为真」判定分支——`isAudio` 只在听书平台（喜马拉雅/蜻蜓/酷我酷狗听书）为
true，音乐平台为 false，于是音乐被判进「视频」分支，把视频清晰度档位码（`fhd`）当音质参数发给服务端；
服务端对音乐平台的非音质值按非法音质拒绝（422 `invalid_quality`，错误体 100 字节，与线上 nginx
日志逐字节吻合）。听书与影视分集不受影响，因此表现为「只有音乐站不能用」。

修复：改用 `MusicPlatform.isVideo`（仓库既有，下载路径一直用它）判定，并抽出纯函数
`onlineResolveQualityValue(platform, audioQuality, videoQualityCode)` 作为唯一判定来源——视频站直传
清晰度档位码，音乐与听书发送音质枚举值。共改 2 个文件（`OnlineModels.kt`、`NativeMusicViewModel.kt`
的播放路径与预解析两处），新增 1 个回归单测文件。服务端无改动。
