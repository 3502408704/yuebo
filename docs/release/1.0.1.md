## 变更摘要

1. **在线歌词不再误报登录失效**：`NativeMusicViewModel.fetchAndSaveOnlineLyrics` 在未登录月播账号时
   直接跳过（此前未登录播本地歌会抛 `login_required` 弹「登录已失效，请重新登录」误报）；播放链路对
   歌词拉取整体 `runCatching` 包裹，歌词失败（含登录态中途失效）绝不中断播放。
2. **账号页操作失败弹窗提示**：`YueboAccountScreen` 账号操作（登录/注册/改密等）失败时，除原行内
   错误文案外新增 `AlertDialog` 明确展示失败原因（账号或邮箱已被使用、账号或密码错误等），并在
   对话框出现时 `announceForAccessibility("操作失败，…")` 同步播报；对话框按钮「知道了」≥48dp，
   关闭后行为与既有对话框一致。
3. 无其他行为变更；包名与 1.0 一致（`com.yuebo.player`），1.0 用户应用内直接升级。
