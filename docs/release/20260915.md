## 变更摘要

本版为客户端功能与体验更新，新增直播模块与聚合视频站点「影视仓」，并修复已知问题。

### 新增

- **直播模块**：可观看电视台、收听广播电台（央视频道/卫视频道/少儿动画/港澳台/地区频道 + 蜻蜓电台等）。
  三方源自动拉取；若某源不能播放又无法替换，等待其自主修复，或者作者偶遇仙缘。
- **视频站点「影视仓」**：聚合多个采集源，资源比较全，但稳定性欠佳，将就看看。同剧多源命名差异自动合并去重；
  播放失败自动到其它同名片源换源并保持播放进度（断点续播）。
- **视频清晰度入口（多码率适配）**：可切码率影视在「更多」菜单提供清晰度档位，热切换不丢进度。
- **会员时长展示**、**播放历史清空**、**跳过片头片尾总开关**、**服务端标识门禁**（`X-App-Id`/`X-App-Version`）。

### 优化

- 注册提示更清晰；视频缓冲按实测吞吐动态伸缩；影视仓搜索 5 秒软截止 + 更严的黄赌毒过滤；
  收藏夹连续播放；在线搜索短期缓存与稳定性修复。

### 修复

- **应用启动闪退**（`AdaptiveLoadControl` 委托默认方法抛异常 → 显式实现全部方法）。
- **影视仓视频无法播放**（多码率变体代理地址未通过授权 → 清单端点接受账号绑定与 URL 绑定两种签名）。
- 修复已知问题。
