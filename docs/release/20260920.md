## 变更摘要

### 修复：检测更新报「网络错误」

- **根因（生产取证）**：gitcode 内容 API（`/api/v5/...contents/update.json`）的**共享匿名账号
  `p_repoRobot` 每小时 10 万次配额周期性打爆**，返回 429 错误体；客户端 `fetchUpdateInfo` 对
  4xx/错误体一律判失败 → 「检查失败，请检查网络连接」。与月播服务器无关，所有用户同期受影响。
- **修复（三层）**：
  ① 服务端 nginx 托管更新清单镜像 `https://124.223.159.230/update.json`（80/443 两块都加了
  `location = /update.json`，静态文件 `/var/www/update/update.json`，发版流程新增同步步骤）；
  ② 客户端 `UpdateChecker.fetchUpdateInfo(urls)` 改多源依次尝试：**自家服务器镜像优先 →
  gitcode API 兜底**；解析抽出纯函数 `parseUpdatePayload`（兼容 gitcode base64 包装与裸
  update.json，限流错误体判 null 落到下一源）；
  ③ 发版流程文档新增 3.5 步（镜像同步）。
