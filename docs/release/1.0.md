## 变更摘要

1. **包名变更（本批核心）**：applicationId 改为 `com.yuebo.player`，与「月播」品牌对齐。
   - 老包用户（0.6.8/0.6.9）应用内更新会下载但**无法覆盖安装**（不同包），需手动安装本版并重新登录；
   - 本地播放列表/历史不迁移；已下载音乐与导入专辑在公共目录 `Music/月播`，新版扫描/导入即可；
   - manifest authority 使用 `${applicationId}` 占位符自动跟随；JNI/R 类绑代码包不受影响；
   - 旧包应用的在线更新源仍指向同一 update.json，**老包用户装不上 1.0 属预期行为**，需人工告知换装。
2. **会员价格展示（本批）**：开通会员页新增「会员价格」区——`¥3/月`（headlineSmall 主色）+
   `原价¥8/月`（划线 `TextDecoration.LineThrough`）+ 说明文案「当前为限时折扣价；折扣活动会随市场情况
   和资源内容的添加结束，结束后恢复原价」。常量：`MEMBERSHIP_MONTHLY_PRICE_YUAN = 3`、
   `MEMBERSHIP_MONTHLY_LIST_PRICE_YUAN = 8`（客户端常量承载，**调价需重新发版**；会员服务协议正文
   不含价格，调价无需升协议版本）。
3. 功能层面与 0.6.9（同日发布）一致，无其他行为变更。
