## 变更摘要

见 `CHANGELOG.md` 的 `[0.6.9]` 小节。本版为首个「月播」正式版，核心新增：

1. **开通会员自助流程（本批）**：月播账号页「开通会员」→ 首次强制阅读并同意《会员服务协议》
   （`MEMBERSHIP_AGREEMENT_VERSION = 1`，同意版本持久化于 `app_consents/membership_agreement_accepted_version`，
   协议改版 +1 重新征求）→ 开通页展示微信/支付宝收款码（复用赞助页资源 `R.drawable.wechat_qr`/`alipay_qr`，
   点击放大）→「复制QQ号」按钮（管理员 QQ `3502408704`，写入剪贴板并 liveRegion 播报）→
   用户凭付款订单与账号名联系管理员人工开通。
2. **关于页移除开源技术清单（本批）**：`openSourceTechs` 列表与关于对话框渲染块整体删除。
   注意：应用内不再展示开源署名（jaudiotagger LGPL-2.1 / Fetch2 / Media3 / unrar 等），许可证信息以源码仓库为准。
3. 自 0.6.8 以来累积的未发版工作（更名月播、MV、播放历史三分类、视频播放页 B 站化、用户协议、
   官方影视搜索翻页/分集补全、点击即播等）随本版一并发出。
4. 服务端上线前稳定化（本批）：周期清理循环（过期解析缓存/终态任务/旧请求事件/限流桶/过期会话/过期网盘缓存，
   `ONLINE_MEDIA_CLEANUP_INTERVAL` 默认 900s，0 关闭）、迁移 0014（api_request_events.created_at 索引）、
   跨进程队列轮询退避（50ms×1.5 封顶 250ms）、/healthz 增加 database/queues/caches 观测字段。
