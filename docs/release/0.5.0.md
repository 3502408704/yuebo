# 汪汪播放器 0.5.0 发布日志

发布日期：2026-07-26  
版本：`0.5.0 (5001)`  
架构：`arm64-v8a`

## 新增

- 搜索歌曲、歌手和专辑。
- 收藏歌曲及“只看收藏”筛选，收藏数据保留在设备本地。
- 断点续播：恢复上一次曲目与位置，启动时不自动播放。
- 显示内嵌专辑封面。
- 显示 Lyrics3、Vorbis 和 APE 音频标签中的内嵌歌词。

## 改进

- 正在播放页可滚动，长歌词和大字体下仍可访问播放控制。
- 保持既有队列、播放模式、通知栏、锁屏和耳机按键媒体控制。
- 曲库搜索或收藏筛选为空时提供可读反馈。

## 已知边界

- 不联网获取歌词，也不读取外置 `.lrc` 文件。
- 本包仅包含 `arm64-v8a`。
- DLNA、Chromecast、蓝牙路由和 TalkBack 仍需按 `AGENTS.md` 进行真机验收；未完成前不得宣称设备支持。
