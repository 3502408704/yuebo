## 变更摘要

- 扩展本地音频格式支持：MP3、OGG/OGA、FLAC、WAV、AIFF/AIF、MP1/MP2、M4A/AAC/M4B、APE、Opus、WavPack（WV）、DSD（DSF/DFF）、WebM 和 MKA。
- 增加网易云、QQ 音乐、酷我和酷狗流媒体音源；酷狗当前暂不可用。
- 支持流媒体歌曲下载到本地，以及 DLNA/Chromecast 投送。
