## 变更摘要

### 修复

- **启动闪退（20260915 撤回原因）**：`NativeVideoPlayer.kt` 的 `AdaptiveLoadControl` 用 Kotlin
  `LoadControl by delegate` 委托，只为**抽象方法**生成了转发；`LoadControl` 的其余方法带 Java 默认实现，
  其中废弃的无参重载默认体是 `throw IllegalStateException("… not implemented")`。ExoPlayer 内部调用的是
  `xxx(PlayerId)` 重载，它默认转发到那个会抛异常的无参重载 → 构建播放器（ViewModel 初始化）时
  `Cannot create an instance of NativeMusicViewModel` / `getBackBufferDurationUs not implemented`。
  **修复**：不再委托，像 `DefaultLoadControl` 一样显式实现 ExoPlayer 实际调用的全部 10 个方法。

### 新增

- **播放历史清空**：播放历史页顶栏新增「清空」入口（当前标签页有记录时才显示），点击弹确认对话框，
  按当前「音乐/听书/视频」标签清空对应记录（含播放进度），操作后 TalkBack 播报「已清空…播放历史」。
- **跳过片头片尾总开关**：更多菜单新增开关；**关闭时**隐藏「跳过片头片尾设置」入口并把当前歌曲所属专辑/
  文件夹的跳过秒数清零（关闭即清零生效），**打开后**才显示设置项且跳过才生效。

### 优化 / 变更

- **服务端标识门禁**：客户端所有发往月播服务端的请求都携带 `X-App-Id: com.yuebo.player` 与
  `X-App-Version: <versionCode>`（业务接口经 `YueboAccount.request`/`RemoteOnlineCatalog`，媒体请求经
  `ResolvingDataSource` 包装、投送经 `LocalMediaServer`、下载经 `DownloadEngine`）；服务端新增中间件门禁，
  **只接受本应用且不低于要求版本的请求**，其余返回 426 并提示升级。门禁由服务端配置开关控制
  （`ONLINE_MEDIA_APP_CLIENT_ID` / `ONLINE_MEDIA_APP_REQUIRED_VERSION`），未配置时不启用。
  **注意：服务端启用门禁后，旧版客户端将收到 426 提示升级——需先部署服务端并按需设置最低版本号。**
