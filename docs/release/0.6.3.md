## 变更摘要

- 视频播放：本地曲库新增"视频"浏览（缩略图/格式/时长/大小），点击进入独立全屏视频播放器，支持暂停/继续、上一集/下一集、进度拖动、音量与结尾自动切集。
- 云端视频：百度网盘目录内视频文件可在线全屏播放（走本地代理，支持进度拖动 seek）。
- 视频使用 Media3/ExoPlayer（MediaCodec 解码），音频仍由 BASS 负责；开始播放视频时自动暂停音乐，退出后不自动恢复。
- 视频播放器全屏体验：进入即沉浸式（隐藏状态栏/导航栏），控制条隐藏时顶栏同步隐藏，双击画面暂停/继续，支持"进入全屏"横屏切换并在退出时恢复竖屏。
- 视频投送（本地视频）：可投送到 DLNA/Chromecast 设备，投送中暂停/继续/进度可控制，支持返回本机从远端位置续播；云端视频因回环代理限制暂不支持投送，给出中文提示。
- Android 13+ 新增"视频读取权限"（READ_MEDIA_VIDEO），权限设置向导与本地音乐提示文案同步更新为音频与视频。
