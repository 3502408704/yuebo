## 变更摘要

- 百度网盘支持文件夹整体下载，下载速度视个人网盘会员情况而定。
- 创建新的下载任务时会明确提示"已加入下载队列"。
- 修复媒体库无法解析视频所在文件夹的问题，文件夹浏览中视频现已正确归类与统计。
- 修复在线媒体搜索后，从后台切回前台时搜索框/软键盘被强制弹出的问题。
- 迷你播放器由常驻显示改为停止播放 3 秒后自动隐藏。
- 在线媒体站点选择默认网易云，切换站点后自动记忆，下次进入保持上次选择。
- 优化整体 UI 流畅性：动态配色缓存、列表派生数据记忆化、视频缩略图解码移出主线程。
