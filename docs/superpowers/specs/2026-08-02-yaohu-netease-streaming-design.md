# 曜狐网易云流媒体重构设计

日期：2026-08-02

## 目标与范围

将已失败的导入音源、QuickJS 和本地代理路线替换为曜狐 API 直连方案。第一阶段只接入网易云，提供搜索、播放和下载。保留底部三个 Tab：本地媒体、在线媒体、设置。播放列表从原“我的”区域移动到播放器页面。

本次不修改本地导入、已有本地曲库、保存的本地播放列表、投送、蓝牙和更新流程。不接入 QQ、酷我或其他平台；后续平台使用同一曜狐请求层，但各自声明其接口字段和音质挡位。

## 架构

```
OnlineScreen
  -> YaohuApiClient（曜狐域名、密钥、超时、错误响应）
  -> NeteaseCatalog（网易云搜索和单曲解析）
  -> NativeMusicViewModel（队列、状态、下载协调）
  -> NativeBassPlayer.playUrl（直接播放解析 URL）
```

`YaohuApiClient` 是唯一共享层：从 `BuildConfig` 读取随 APK 分发的密钥，构造请求并解析 HTTP 失败。它不是通用音源插件框架。`NeteaseCatalog` 负责网易云端点 `/api/music/wyvip` 的搜索和按序号单曲解析；未来平台各自增加小型 catalog，不共享未经验证的响应模型。

搜索使用关键词和该平台的播放音质。结果保存原始搜索词和服务端序号。用户播放或下载时，以搜索词、序号和对应的播放或下载音质再解析一次单曲。优先使用 `vipmusic.url` 作为 BASS 直连播放地址和下载地址；仅在该字段不存在时尝试顶层 `url`。不使用本地 HTTP 代理、QuickJS 或第三方音源脚本。

密钥由未提交的 `local.properties` 注入 `BuildConfig`，不会写入源码、Git、偏好设置、日志或界面。密钥会随 APK 提取，这是已确认的部署取舍。

## 导航与交互

底部导航固定为：

1. 本地媒体：保留现有曲库。
2. 在线媒体：网易云搜索框和搜索结果。
3. 设置：保留现有设置与关于页，移除“我的”和音源管理入口。

在线页只在用户明确提交搜索时发起网络请求。点击搜索结果会以当前搜索结果建立临时在线队列，并直接交给 BASS 播放。在线队列不跨进程恢复；成功下载的歌曲则作为普通本地媒体持久化。迷你播放器显示在三个 Tab 的内容上方。

搜索结果条目普通点击播放；长按当前条目显示下载图标。下载图标有 48dp 目标和“下载”中文语义。条目同时暴露等价的 TalkBack 自定义操作“下载”，无需长按手势。长按不会播放。搜索、解析和下载期间禁用重复操作，并使用中文 live region 状态反馈。

播放器页新增“播放列表”入口，进入全屏播放列表页。该页保留当前队列、播放历史和已保存列表，返回后回到播放器页面且不中断播放。

## 平台音质

音质以“平台 + 用途”独立保存，而非全局设置。当前设置页提供：

- 网易云默认播放音质，初始值为极高。
- 网易云默认下载音质，初始值为无损。

网易云支持的挡位为标准、较高、极高、无损、Hi-Res、高清环绕、沉浸环绕和超清母带，分别映射曜狐 API 的平台参数。未来新增平台时，在设置页增加该平台自己的播放和下载音质项，只展示其已声明支持的挡位，不强行映射不同平台的质量名称。

解析后 UI 显示服务端实际返回的音质；若服务端降级，不显示为用户请求的音质。

## 下载、失败处理与迁移

下载按歌曲所属平台的下载音质解析。下载内容通过 `MediaStore.Audio` 写入 `Music/汪汪播放器/`，文件名为安全化的“歌手 - 歌名”，优先使用服务端返回的格式。写入失败时清理未完成条目；完成后刷新本地曲库，因此歌曲可离线播放、投送和加入现有本地播放列表。

网络超时、服务端错误、无可用播放地址和下载写入失败都显示服务端中文消息或明确的本地中文错误，不暴露密钥。操作不自动重试，由用户再次点击重试。

移除旧的 MusicFree/LX 音源、QuickJS、代理服务、音源管理界面及其 Gradle 依赖与状态。旧在线队列、音源偏好和旧全局在线音质偏好不恢复。本地曲库、保存的本地播放列表、历史、导入、投送、蓝牙和更新流程不迁移也不改行为。

## 验证

- 使用脱敏 JSON 固件测试网易云搜索、单曲解析、URL 选择、服务端错误与每个质量参数。
- 测试按平台保存播放/下载质量，以及下载文件名、MediaStore 写入和失败清理。
- Compose 测试覆盖显式搜索、长按显示下载入口和条目的“下载”无障碍自定义操作。
- 实现后运行 `rtk git diff --check`、相关单元测试和 `assembleRelease`。
- 在可用 Android 设备上验收网易云搜索、播放、下载入库、质量设置、长按下载、TalkBack 操作和播放列表迁移；同时回归本地播放、投送与蓝牙。
