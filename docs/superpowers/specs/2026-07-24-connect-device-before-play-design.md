# 先连接设备后播放设计

## 目标

允许用户在未播放歌曲时连接 DLNA 设备；连接后从媒体库选择歌曲默认投送。恢复始终可见的投送入口，并简化目录返回导航。

## 交互

- AppBar 标题固定为“本地音乐”，右上角始终提供“投送到设备”入口。
- 用户显式打开设备选择器、选择设备并确认连接时，只保存连接目标，不加载媒体、不播放音频、不启动本地 HTTP 媒体服务。
- 已连接设备显示为当前播放目标；用户随后在任意目录激活歌曲时，才创建 DLNA 会话并在设备端播放。
- 未连接时激活歌曲维持本机播放；投送中仍保留明确的“返回本机播放”。
- 非根目录仅在 AppBar 左上角显示标准返回箭头；系统返回手势与该箭头都返回上级目录。列表中不再显示“返回上级文件夹”行。

## 无障碍与错误

- 设备入口、连接状态和返回按钮均有简短中文名称；选择设备不会开始网络媒体投送。
- 设备连接、首次投送或后续换歌失败显示可恢复错误，且不自动切换为手机播放。
- 按用户要求不新增、修改或运行自动化测试；验收使用真机和设备人工测试。
