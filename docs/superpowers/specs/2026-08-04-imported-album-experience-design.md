# 已导入专辑体验设计

**日期：** 2026-08-04

## 目标

把媒体库的“专辑”浏览改为仅显示用户通过“导入文件夹”登记的专辑。每张专辑提供封面、封底、简介、可编辑的应用内元数据、保留的 CUE 分轨，以及类似 Apple Music 的专辑详情体验。

## 范围

- 直接导入文件夹时登记或更新一张专辑，同时继续创建现有播放列表。
- 专辑目录不会根据 MediaStore 的 `ALBUM` 标签或普通文件夹自动发现。
- 歌曲、文件夹、艺术家浏览保持现有行为。
- 元数据只保存为应用内覆盖，不修改原始音频文件或其标签。
- 不新增第三方依赖，不改变播放器、投送或蓝牙的控制路径。

## 数据模型与持久化

新增持久化的 `ImportedAlbum`，由 `NativeMusicViewModel` 加载、更新和保存。每条记录包含：

- 稳定 `id`；
- `name` 与可选 `artist`；
- 目录 `treeUri`；
- 已收集曲目的 `trackUris`；
- 可选 `frontCoverUri` 与 `backCoverUri`；
- 可选 `description`；
- 以曲目 URI 与 CUE 起始位置为键的标题、艺术家、专辑名等曲目元数据覆盖。

专辑 JSON 独立于既有播放列表 JSON 保存。重新启动时通过已持久化的目录/文件 URI 恢复曲目；失效 URI 不导致崩溃，并在详情页保留可见的提示。

## 导入流程

“导入文件夹”取得目录持久化读取权限后，递归枚举音频、CUE、图片和 `简介.txt`：

1. 收集支持的音频 URI 并生成外部曲目。
2. 对同目录的 CUE 沿用现有 UTF-8 严格解码、GB18030 回退与 `expandCueTracks` 规则，生成分轨、起始时间和时长。
3. 以文件夹显示名作为默认专辑名，按稳定目录 ID 更新现有专辑或创建新专辑。
4. 从目录中匹配默认封面、封底和简介；已由用户编辑的覆盖值优先，不被再次导入覆盖。
5. 保留当前“创建播放列表并播放第一首”的行为。

默认封面候选名为 `cover`、`front`、`folder`、`albumart`；默认封底候选名为 `back`、`backcover`、`封底`。支持 jpg、jpeg、png 和 webp。`简介.txt` 为初始简介，用户保存的简介优先。

## 媒体库与详情页

在“专辑”浏览模式：

- 仅使用已导入专辑记录创建列表；不再调用现有 `albumCollections` 进行自动分组。
- 每项显示封面、专辑名、艺术家（存在时）与曲目数。
- 点击仅打开详情，不开始播放。

专辑详情页采用纵向、留白充足的音乐浏览样式：

1. 顶部应用栏提供返回和“编辑专辑”。
2. 顶部显示大封面、专辑名、艺术家、曲目数与简介摘要。
3. 中部是稳定排序的轨道列表，保留 CUE 分轨及其时长。点击一条曲目才调用现有队列播放。
4. 列表末尾显示封底和完整简介。
5. 每条轨道提供明确的“编辑元数据”入口。

封面、碟面和封底是纯视觉展示：`contentDescription = null`，不设可点击语义或无障碍焦点。专辑和曲目的文字信息与编辑操作有独立的中文语义节点。

## 编辑行为

“编辑专辑”对话框允许修改专辑名称、艺术家、封面、封底和简介；封面/封底通过系统文件选择器选择，持久化读取权限后保存 URI。编辑曲目对话框允许修改标题、艺术家和专辑名。

歌曲与文件夹浏览中的每首曲目也提供同一个“编辑元数据”入口。覆盖记录独立于专辑保存，并在 MediaStore 刷新、外部文件恢复和 CUE 展开后统一应用；因此用户可以在媒体库任一浏览方式编辑歌曲，而导入文件夹的专辑级信息仍由专辑记录保存。

所有编辑立即更新应用状态和持久化 JSON。它们不尝试写入媒体文件，也不依赖外部文档提供者的写权限。

## 动效

- 打开详情页时，封面采用短暂的缩放和淡入过渡；优先使用当前 Compose BOM 可用的稳定 API。
- 轨道列表滚动时，碟面随滚动距离做有限、低成本的旋转；到达列表结尾后停止动画，使封底保持稳定可见。
- 页面离开组合树时停止动画。
- 系统移除动画/减少动效时，不运行翻开与旋转效果，页面仍可完整浏览和操作。

动效不表达状态或功能，不影响轨道点击、返回和键盘操作。

## 无障碍与导航

- 专辑项、轨道项、编辑入口、保存/取消按钮均有简短中文语义名，点击目标至少 48dp。
- 专辑项和轨道项使用稳定 key；焦点移动本身不触发播放、导入或写入。
- 从详情页返回时，回到原专辑项并恢复列表位置和可访问性焦点；从编辑对话框返回时，焦点回到相应编辑入口。
- 导入、保存和失败用可见中文状态文本加 polite live region 通知。
- 在大字体、TalkBack、键盘/D-pad 下保持正常任务顺序，图片不产生额外焦点。

## 测试与验证

自动化测试重点验证：

- 导入目录只创建用户专辑，MediaStore 自动专辑不会出现；
- 专辑记录、图片 URI、简介、元数据覆盖和外部曲目 URI 可持久化并恢复；
- `简介.txt` 仅在没有用户覆盖时作为初始简介；
- CUE 继续展开为专辑轨道，且保留起始时间与时长；
- 专辑列表稳定排序，详情曲目有稳定 key。

交付前执行 `rtk git diff --check`、`rtk cmd /c "gradlew.bat :app:compileDebugKotlin"`、`rtk cmd /c "gradlew.bat :app:assembleRelease"`。设备验收由用户手动完成，交付时提供明确的测试项目：导入、恢复、封面/封底/简介、CUE、元数据编辑、动效、大字体、TalkBack、歌曲/文件夹浏览、播放列表、DLNA/Chromecast 和蓝牙回归。
