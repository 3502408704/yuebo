# 汪汪播放器 v0.1 正式发布设计

## 发布标识

- Android 显示名称：汪汪播放器。
- 版本：`0.1.0+1`。
- 包名保持 `com.example.local_music_player`，以避免无授权的应用标识迁移。

## 签名与安全

- 生成独立 RSA 2048-bit release keystore，别名为 `wangwang-player`。
- keystore 和 `key.properties` 仅保存在本机，均由 `.gitignore` 排除；仓库只保存读取本机配置的 Gradle 逻辑。
- release 绝不使用 debug 签名。生成后应备份 keystore 和凭据，否则无法向同一应用签名升级。

## 体积与发布构建

- release 使用 R8 `isMinifyEnabled = true` 和 `isShrinkResources = true`。
- Flutter release 构建使用 `--obfuscate --split-debug-info=<本机符号目录>`；符号目录不入库。
- 不添加依赖；保留运行所需的 BASS ABI 与 audio_service 组件。
- 构建 signed release APK，验证 APK 签名和文件存在；按用户要求不运行自动化测试。
