支持的音频格式（内置解码，无需担心格式）
＝＝＝＝＝＝＝＝＝＝＝＝＝＝

CUE 分轨与压缩包导入
＝＝＝＝＝＝＝＝＝＝＝＝＝＝
支持解析 CUE 文件（.cue / .cue.txt）：整轨专辑自动按 CUE 分成单曲，每一轨都能单独播放、收藏、加歌单。
压缩包直接导入：zip、rar（含加密 RAR，密码弹窗输入）、tar、tar.gz，导入即整理成专辑。
