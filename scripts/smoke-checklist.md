# 月播 冒烟清单

> 发布前或涉及导入/播放/UI 的改动后，在真机上按序执行；每一项给出 通过/失败 与备注。

## 准备

- 安装 `build/app/outputs/apk/release/` 下的英文命名 APK（`adb install -r`）。最终包体文件名只能使用英文字母/数字/`-`/`_`/`.`，禁止中文或其他非 ASCII 字符。
- 授予"所有文件访问"权限。
- 设备时间与 `current_date` 一致。

## 冒烟步骤

1. 启动应用，无闪退；首次进入曲库完成扫描。
2. 歌曲浏览可列出 MediaStore 音频。
3. 点击歌曲开始播放；暂停、继续、seek、音量正常。
4. 队列自动下一首正常（含 CUE 分轨曲目）。
5. 导入 zip：`adb shell am start -a android.intent.action.VIEW -d file:///sdcard/Download/<x>.zip -t application/zip`，确认自动解压到 `Music/月播/<专辑名>/`（旧版本导入的 `Music/汪汪播放器/` 内容仍应在曲库可见）。
6. 加密 RAR：确认弹密码框，错误密码提示、取消无残留。
7. 专辑浏览：未知专辑/单曲导入不出现；导入专辑按一级子文件夹名归类。
8. 文件夹浏览与歌曲浏览可见无专辑歌曲。
9. 系统"用其他应用打开"：`cmd package query-activities -a android.intent.action.VIEW -t application/zip` 匹配本应用。
10. TalkBack 开启下：专辑页、正在播放页、导入进度与密码对话框可读、可操作。
11. `logcat` 无 FATAL/ANR。

## 在线流媒体（内置妖狐 yaohu / ShyMusic）

> 前置：设备联网；底部导航三 Tab：本地音乐 / 在线流媒体 / 我的。

12. 在线搜索：在线流媒体页选择平台（网易云/QQ/酷我/酷狗）输入关键词 → 结果列表；加载更多正常；无结果有中文提示。
13. 在线播放：点搜索结果 → 开始播放；正在播放行有"正在播放"文本+语义；切歌/暂停/继续/seek 正常。
14. 音质切换：我的-设置-音质选择中各平台播放/下载音质可切换并持久化；播放后实际音质展示正确。
15. 妖狐兜底：主源解析失败时自动尝试其他解析路径，失败给中文提示，应用不闪退。
16. 在线下载：在线结果/专辑详情可下载；下载管理显示进度，暂停/继续/重试、断点续传正常。
17. 在线专辑：搜索切到专辑视图可打开专辑详情，播放/下载专辑曲目正常。
18. 返回本机：播放在线曲目后切回本地曲目，本机播放正常。
19. TalkBack：在线页平台切换/搜索/结果行/专辑/下载可读可操作；浏览不触发网络。
20. 体积回归：`logcat` 无 FATAL/ANR。

### 在线封面与播放稳定性（0.6.2 新增）

21. 封面展示：四平台搜索歌曲行、专辑行、专辑详情头部、正在播放页与迷你播放器均显示封面；无封面源显示兜底图标不崩溃。
22. 封面缓存：同一结果列表上下滚动再回到原位不重复请求封面（观察 logcat/抓包 pic 请求次数）；内存紧张（`adb shell am send-trim-memory <pid> HIDDEN`）后封面可重新加载不崩溃。
23. 断源换源：首次播放时若 ShyMusic 地址打不开，自动走妖狐同平台兜底并成功出声（不报错、不闪退）；同一曲目再次播放直接命中缓存地址，`logcat` 不重复出现 qq_url/wyy_url 等解析请求。
24. 换源可靠性：播放中途地址失效（模拟断网/服务端 403）后重新点击播放，能换源成功；不出现"卡死"或无限 loading。
25. TalkBack 封面：歌曲行/专辑行为单一可操作节点，封面不产生额外焦点；正在播放页封面有"歌曲封面：xxx"描述。
26. 回归：在线封面改动后重跑本地播放、DLNA、Chromecast、蓝牙路由与 TalkBack 关键路径。
27. `logcat` 无本应用 FATAL/ANR。

## 视频播放（0.7.0 新增）

> 前置：本地曲库存在 MediaStore 视频（相机/下载目录）；Android 13+ 已授予音频与视频读取权限。

28. 本地视频：曲库"浏览"菜单切到"视频"，列出 MediaStore 视频，行显示缩略图/格式/时长/大小；无视频设备显示"未找到视频文件。"。
29. 本地播放：点击视频行进入全屏播放器并自动播放；返回按钮退出并回到原 Tab；顶部标题为视频名。
30. 播放控制：暂停/继续、上一集/下一集、进度拖动 seek、音量调节均正常；播放中点击画面可切换控制条显隐。
31. 自动切集：视频播放到结尾自动播下一集；末集播放结束后停在结尾不跳转、不闪退。
32. 切集后返回本机音频：退出视频后音频播放器仍处于暂停状态（不自动恢复，符合设计）。
33. 权限：Android 13+ 权限设置向导含"音频与视频读取权限"步骤，允许后可浏览视频；未授予时视频页显示中文提示。
34. 云端视频：百度网盘"云端存储"目录内视频文件点击后进入全屏播放；进度拖动走代理 Range 正常；切集重开代理不卡死。
35. 不支持格式：AVI/WMV/RMVB 等无法解码时显示中文错误提示，应用不闪退。
36. 横竖屏与后台：旋转屏幕不崩溃；切后台自动暂停视频，回到前台仍暂停。
37. TalkBack：视频页控件（返回/播放暂停/上一集/下一集/进度/音量）均有中文语义；TalkBack 开启时控制条不自动隐藏、不困焦点。
38. 回归：视频改动后重跑本地播放、在线播放、DLNA、Chromecast、蓝牙路由与 TalkBack 关键路径；`logcat` 无本应用 FATAL/ANR。

## 视频全屏与投送（0.7.0 新增）

39. 全屏：进入视频播放器隐藏状态栏/导航栏（沉浸式）；点击画面切换控制条，控制条隐藏时顶栏同步隐藏；双击画面暂停/继续；控制条"进入全屏"按钮切换横屏，退出视频页恢复竖屏。
40. 本地视频投送：视频播放器"投送到设备"→ 搜索 → 选择 DLNA/Chromecast 设备 → 视频在设备播放，画面显示"正在投送到 xxx"；投送中暂停/继续/seek 生效；"返回本机"从远端位置续播本机；投送中上一集/下一集禁用。
41. 云端视频投送：点击投送显示"云端视频暂不支持投送"中文提示，应用不闪退。
42. TalkBack：投送对话框（设备列表/搜索/返回本机）与投送状态可读可操作；投送中不困焦点。
